Wild Cat Payroll — تحويل البرنامج لتطبيق أندرويد (APK) عن طريق GitHub
=====================================================================
المشروع جاهز: أول ما ترفعه على GitHub، GitHub بيبني ملف APK لوحده ويحطه لك للتحميل. ما تحتاج تثبّت أي حاجة على جهازك.

الخطوات
-------
1) سجّل في github.com (مجاني) واعمل Repository جديد:  New repository ← الاسم مثلاً wildcat-payroll ← Private (يُفضّل) ← Create.
2) ارفع محتويات هذا المجلد كلها (مش المجلد نفسه): في صفحة الـ repo اضغط «uploading an existing file»، واسحب كل اللي جوا المجلد:
   مجلد .github  +  مجلد www  +  package.json  +  capacitor.config.json  +  .gitignore
   تأكد إن مجلد .github اترفع (فيه الملفين build-apk.yml و pages.yml)، ثم اضغط Commit changes.
   (بديل أسهل لو واجهت مشكلة في الرفع: برنامج GitHub Desktop واسحب المجلد.)
3) افتح تبويب Actions ← هتلاقي «Build Android APK» شغال تلقائياً (لو مش شغال: اختاره واضغط Run workflow). ياخد 5–10 دقايق.
4) بعد ما يخلص بعلامة ✓ خضراء، حمّل الـ APK من واحد من مكانين:
   - تبويب Releases (يمين صفحة الـ repo) ← أحدث Release ← ملف WildCat-Payroll.apk  (الأسهل من الموبايل مباشرة).
   - أو من صفحة الـ run نفسها ← Artifacts ← WildCat-Payroll-APK.
   (لو الـ repo خاص، لازم تفتح الرابط وأنت مسجّل دخول على GitHub.)
5) على موبايل أندرويد: افتح الملف المحمّل واسمح بـ «التثبيت من مصادر غير معروفة» لمتصفحك/مدير الملفات، ثم ثبّت.
   (الملف موقّع بتوقيع تجريبي debug — كافٍ للاستخدام الشخصي. لو ظهر تحذير Play Protect اختار «تثبيت على أي حال».)

تسجيل الدخول بنفس حسابات الكمبيوتر
-----------------------------------
 1. على الكمبيوتر: «الأجهزة والتحكم» ← تفعيل المزامنة على مجلد Google Drive ← هيظهر ملف payroll-data.json.
 2. على الموبايل: أول شاشة ← «ربط هذا الجهاز بنظام موجود» ← «اختيار الملف…» ← اختار payroll-data.json من Drive.
 3. سجّل الدخول بنفس حساباتك (المدير يضيفها من الكمبيوتر).
 - لإرسال تعديلات الموبايل: زر 🔄 فوق ← «② حفظ ملف التغييرات» ← يفتح قايمة المشاركة ← اختار Drive واحفظه مكان الملف القديم بنفس الاسم (Replace).
 - لجلب تعديلات الكمبيوتر: زر 🔄 ← «① تحديث من ملف Drive» وتختار الملف تاني. الدمج تلقائي.

حدود نسخة الـ APK (بسبب قيود أندرويد، مش عيب في البرنامج)
---------------------------------------------------------
 - المزامنة المباشرة مع Google Drive غير متاحة داخل الـ APK (جوجل بتمنع تسجيل الدخول داخل التطبيقات المدمجة) — المتاح تبادل الملف (طريقة 1). المزامنة المباشرة متاحة في النسخة الويب (تحت).
 - الطباعة وحفظ PDF مباشرة غير متاحين داخل الـ APK. التقارير تتصدّر Excel وتتشارك. للطباعة استخدم الكمبيوتر أو النسخة الويب على Chrome.
 - لم أستطع تجربة بناء الـ APK نفسه من عندي (بيحتاج خوادم GitHub). لو فشل الـ run: افتح الـ run المعلّم ✗ وانسخ آخر 20 سطر من الخطأ وابعتهم لي وأصلحه.

نسخة الويب (اختياري — فيها كل الإمكانيات: طباعة + مزامنة Drive مباشرة)
-----------------------------------------------------------------
 في الـ repo: Settings ← Pages ← Source = GitHub Actions. ثم Actions ← «Deploy web version» ← Run workflow.
 هتاخد رابط https://اسمك.github.io/wildcat-payroll/ — افتحه من الموبايل وثبّته (Chrome: ⋮ ← تثبيت التطبيق | آيفون Safari: مشاركة ← إضافة للشاشة الرئيسية).
 آيفون: ما فيه APK على آيفون، نسخة الويب هي الحل الوحيد.
